# Política de Privacidad · KING

Página de la política de privacidad del juego **KING**, de Barragán Becerra Studio,
publicada con GitHub Pages.

## Por qué este repositorio existe y es público

Google Play **exige** una política de privacidad accesible en una URL pública para
poder publicar una aplicación. GitHub Pages lo resuelve sin costo, pero en cuenta
gratuita **solo funciona desde repositorios públicos**.

Por eso la política vive aquí, separada del código del juego, que permanece en un
repositorio privado.

## Contenido

`index.html` — la política completa, en español e inglés en la misma página, para
que la revisión de Google no encuentre fricción en ningún idioma.

## Cómo activar GitHub Pages

En este repositorio: **Settings → Pages → Source: Deploy from a branch →
Branch: `main` / `(root)` → Save**.

La URL resultante es la que se pega en Play Console.

## Mantenimiento

Si el juego cambia de forma que afecte a la privacidad —por ejemplo, si algún día
incorpora analíticas, publicidad o guardado en la nube— hay que **actualizar esta
página y cambiar la fecha de vigencia** que aparece al inicio.

Mientras el juego siga sin recoger datos, esta política no necesita cambios.
